🍔 Swiggy Food Order Analytics Dashboard

An interactive Excel dashboard that analyzes Swiggy food order data to track sales trends, customer ratings, top cities, and category performance.

📊 Features
KPI Cards: Total Sales, Average Rating, Avg Order Value, Rating Count, Total Orders
Trends: Monthly, weekly, and daily sales charts
Breakdowns: Sales by food type, state (map), and Top 5 cities
Quarterly table with color-coded Sales, Rating, and Orders
Slicers: Filter by Month, Category, and Restaurant Name


🛠 Tools Used

Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, Conditional Formatting)
